# n8n Automation Skill

This skill enables creating and managing n8n workflows for automation.

## Quick Reference

```bash
# List all workflows
curl -s "$N8N_URL/api/v1/workflows" \
  -H "X-N8N-API-KEY: $N8N_TOKEN" | jq '.data[] | {id, name, active}'

# Execute a workflow
curl -X POST "$N8N_URL/api/v1/workflows/<id>/execute" \
  -H "X-N8N-API-KEY: $N8N_TOKEN"
```

**Required env var**: `N8N_TOKEN` (auto-generated by bootstrap)

## API Operations

### List Workflows

```bash
curl -s "$N8N_URL/api/v1/workflows" \
  -H "X-N8N-API-KEY: $N8N_TOKEN" | jq
```

### Get Workflow Details

```bash
curl -s "$N8N_URL/api/v1/workflows/<workflow_id>" \
  -H "X-N8N-API-KEY: $N8N_TOKEN" | jq
```

### Create Workflow

```bash
curl -X POST "$N8N_URL/api/v1/workflows" \
  -H "X-N8N-API-KEY: $N8N_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My Workflow",
    "nodes": [
      {
        "parameters": {},
        "name": "Start",
        "type": "n8n-nodes-base.start",
        "typeVersion": 1,
        "position": [250, 300]
      }
    ],
    "connections": {},
    "settings": {}
  }'
```

### Activate/Deactivate Workflow

```bash
# Activate
curl -X PATCH "$N8N_URL/api/v1/workflows/<workflow_id>/activate" \
  -H "X-N8N-API-KEY: $N8N_TOKEN"

# Deactivate
curl -X PATCH "$N8N_URL/api/v1/workflows/<workflow_id>/deactivate" \
  -H "X-N8N-API-KEY: $N8N_TOKEN"
```

### Execute Workflow

```bash
# Execute without data
curl -X POST "$N8N_URL/api/v1/workflows/<workflow_id>/execute" \
  -H "X-N8N-API-KEY: $N8N_TOKEN"

# Execute with input data
curl -X POST "$N8N_URL/api/v1/workflows/<workflow_id>/execute" \
  -H "X-N8N-API-KEY: $N8N_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"data": {"key": "value"}}'
```

### Delete Workflow

```bash
curl -X DELETE "$N8N_URL/api/v1/workflows/<workflow_id>" \
  -H "X-N8N-API-KEY: $N8N_TOKEN"
```

## Common Workflow Patterns

### Webhook Trigger → HTTP Request

```json
{
  "name": "Webhook to API",
  "nodes": [
    {
      "parameters": {
        "httpMethod": "POST",
        "path": "webhook-path"
      },
      "name": "Webhook",
      "type": "n8n-nodes-base.webhook",
      "typeVersion": 1,
      "position": [250, 300]
    },
    {
      "parameters": {
        "url": "https://api.example.com/endpoint",
        "method": "POST",
        "bodyParametersJson": "={{ $json }}"
      },
      "name": "HTTP Request",
      "type": "n8n-nodes-base.httpRequest",
      "typeVersion": 3,
      "position": [450, 300]
    }
  ],
  "connections": {
    "Webhook": {
      "main": [[{"node": "HTTP Request", "type": "main", "index": 0}]]
    }
  }
}
```

### Schedule → Gitea Check

```json
{
  "name": "Daily Gitea Stats",
  "nodes": [
    {
      "parameters": {
        "rule": {"interval": [{"field": "hours", "triggerAtHour": 9}]}
      },
      "name": "Schedule",
      "type": "n8n-nodes-base.scheduleTrigger",
      "typeVersion": 1,
      "position": [250, 300]
    },
    {
      "parameters": {
        "url": "$GITEA_URL/api/v1/user/repos",
        "authentication": "genericCredentialType",
        "genericAuthType": "httpHeaderAuth"
      },
      "name": "Get Repos",
      "type": "n8n-nodes-base.httpRequest",
      "typeVersion": 3,
      "position": [450, 300]
    }
  ],
  "connections": {
    "Schedule": {
      "main": [[{"node": "Get Repos", "type": "main", "index": 0}]]
    }
  }
}
```

## Useful Automation Ideas

| Workflow | Trigger | Action |
|----------|---------|--------|
| Deploy on push | Gitea webhook | Trigger Coolify deployment |
| Daily backup | Schedule (cron) | Export workflows/credentials |
| Alert on failure | Coolify webhook | Send notification |
| AI response | Webhook | Query OpenClaw, return result |
| Repo sync | Schedule | Mirror repos to backup |
| Call deployed app | Schedule/Webhook | HTTP request to app on coolify network |

## Network Connectivity

n8n is connected to both `paas-network` and `coolify` network, allowing workflows to:
- Communicate with all stack services (Gitea, Coolify, OpenClaw, LobeChat)
- **Call APIs of Coolify-deployed applications** via internal Docker hostnames

```bash
# Example: Call a deployed app from n8n workflow
# If your app is deployed as "my-api", use internal hostname:
curl http://my-api-<uuid>:8080/api/endpoint

# Verify n8n network connectivity
docker inspect n8n --format '{{range $k, $v := .NetworkSettings.Networks}}{{$k}} {{end}}'
# Should show: paas-network coolify
```

## Troubleshooting

### Test API Connection

```bash
curl -s "$N8N_URL/api/v1/workflows" \
  -H "X-N8N-API-KEY: $N8N_TOKEN" -w "\nHTTP: %{http_code}\n"
```

### Check Execution Errors

```bash
curl -s "$N8N_URL/api/v1/executions?status=error" \
  -H "X-N8N-API-KEY: $N8N_TOKEN" | jq '.data[] | {id, workflowId, stoppedAt}'
```

### View Workflow Webhooks

```bash
curl -s "$N8N_URL/api/v1/workflows" \
  -H "X-N8N-API-KEY: $N8N_TOKEN" | jq '.data[] | select(.nodes[].type == "n8n-nodes-base.webhook") | {id, name}'
```
